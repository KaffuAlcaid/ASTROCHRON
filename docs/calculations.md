# 计算说明

[返回首页](../README.md) · [数据来源](data-sources.md) · [SGP4 原理](orbit-model.md)

适用版本：`v0.1.0`

## 轨道传播与坐标

轨道传播采用 Vallado SGP4 C++ 实现，包含近地与深空轨道处理，TLE 和 OMM 均以 WGS-72 常数初始化

SGP4 输出 TEME 坐标系中的位置与速度，程序用格林尼治平恒星时旋转至地球固定坐标，再以 WGS84 椭球计算星下点、卫星高度与观测者位置

地球旋转采用恒星时近似，地球定向参数、极移与大气折射属于当前计算精度之外的影响项

| 显示值 | 定义 |
| --- | --- |
| 卫星高度 | 相对 WGS84 椭球的高度 |
| 运行速度 | TEME 坐标系中的速度大小 |
| 星下点 | 卫星在地球表面的经纬度 |
| 方位角 | 从正北向东计角，范围 0–360° |
| 高度角 | 相对观测者几何地平面的角度 |
| 距离 | 卫星到观测者的直线距离 |
| 距离变化率 | 沿视线的相对速度，正值远离，负值接近 |

观测地点使用相对平均海平面的海拔 $H$，借助 EGM2008 大地水准面起伏 $N$ 换算椭球高

$$h = H + N$$

EGM2008 格网分辨率为 5′，采用双线性插值

## 时间与轨迹

界面时间按观测地点时区显示，轨道历元以 UTC 表示，轨迹覆盖参考时刻前后各 12 h，内部采样对齐 UTC 的 30 s 刻度，时间窗两端按实际时刻取样

过去和未来位置均由所选轨道根数推算，使用历史根数快照可改变推算依据，根数越接近目标时刻通常越有参考价值，卫星机动和阻力变化会影响预测结果

轨道计算频率控制位置和观测数值的更新，绘图刷新频率控制地图动画与时间显示；绘图频率较高时，地图标记在相邻的 SGP4 采样位置之间插值，观测数值仍采用传播结果

时间窗推进时保留已有轨迹采样并补齐两端，过境和地影事件继续精算；更换目标、轨道根数或观测地点后按相应资料重新计算

## 过境与光学条件

过境开始和结束以观测地点设置的最低高度角为准，默认 10°，最高点对应该次过境中的最大高度角

开始、结束与最高点的数值搜索细化到 0.5 s，这一数值表示搜索分辨率，实际预报精度仍取决于轨道根数和观测条件

相邻采样点均低于最低高度角时，若高度角变化率由正转负，程序在该区间内以 0.01 s 分辨率搜索最高点，达到条件后继续搜索开始与结束时刻，天空图包含这些过境关键点

该搜索依赖相邻有效采样间的高度角变化，传播失败造成的采样缺口，以及短于搜索分辨率的临界过境，仍可能影响预报完整性

光学条件区间每 5 s 采样一次，在过境高度角范围内同时满足以下条件

- 卫星完全受太阳照射
- 观测地点太阳高度角为 −6° 或更低

云量、视星等、地形和建筑遮挡需分别结合观测信息判断，暮光条件只表示天空背景的粗略判据

## 太阳、地影与覆盖范围

太阳位置由 Astronomy Engine 计算，卫星处的太阳与地球视圆盘用于判断日照、半影和本影，地球遮挡采用球形近似

地图昼夜线依据太阳方向与地表法向夹角绘制，覆盖范围按卫星高度和最低高度角采用球面几何计算

## 视星等

采用漫反射球相位函数，参考星等为 $m_{ref}$，参考距离为 1000 km，参考相位角为 $\alpha_{ref}$，实际距离为 $r$，实际相位角为 $\alpha$

$$\Phi(\alpha) = \frac{\sin\alpha + (\pi-\alpha)\cos\alpha}{\pi}$$

$$m = m_{ref} + 5\log_{10}\left(\frac{r}{1000\,\mathrm{km}}\right) - 2.5\log_{10}\left(\frac{\Phi(\alpha)}{\Phi(\alpha_{ref})}\right)$$

公式中的相位角使用 rad，界面以 ° 显示，手动参考相位可选 0° 或 90°，QuickSat 表采用 0° 满相条件

卫星位于几何地平线上方且完全受光时显示结果，计算值为大气外视星等估算，单位 mag，数值越小表示越亮

内置资料按卫星编号与国际编号匹配，手动参数和导入资料可提供对应的参考值，卫星姿态、构型、镜面反射、大气消光与云层决定估算值和实测值之间的差异

## 多普勒频移

以标称接收频率 $f_0$、视线距离变化率 $\dot r$ 和光速 $c$ 计算一阶多普勒频移

$$\Delta f = -\frac{\dot r}{c} f_0, \qquad f_{receive} = f_0 + \Delta f$$

其中 $c = 299792.458\,\mathrm{km/s}$，卫星远离时 $\dot r > 0$，接收频率降低

界面输入单位为 MHz，频移显示为 kHz，校正后接收频率显示为 MHz

## 单位

单位采用国际符号，常用距离和速度以 m、km、km/s 表示，角度保留 °，时间保留 s、min、h，轨道平均运动保留 rev/d，星等保留 mag

BSTAR 保留轨道格式中的逆地球半径单位 `R_E^-1`，平均运动导数项保留来源格式的数值和约定
