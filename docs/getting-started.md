# 开始使用

[返回首页](../README.md) · [使用手册](user-guide.md)

## 运行程序

适用版本：`v0.1.0-preview`，Windows 11 x64

将应用包完整解压到一个文件夹，运行其中的 `ASTROCHRON.exe`，保留同目录随包提供的 DLL 和文件夹

设置与轨道资料保存在 Windows 用户配置中，应用文件夹可单独移动

## 选择观测地点

首次启动会打开观测地点窗口，可搜索城市，也可填写地点名称、经纬度和时区

| 项目 | 用途 |
| --- | --- |
| 经纬度 | 计算卫星相对观测者的方向、距离与过境时刻 |
| 海拔 | 观测位置相对平均海平面的高度，单位 m |
| 最低高度角 | 过境开始与结束的高度角门槛，默认 10° |
| 时区 | 界面时间的显示时区 |

启用“选点后自动查询地形海拔”时，程序按地点坐标查询 Open-Meteo；楼顶、观测台等位置可手动填写海拔

点击“保存为常用地点”可保留当前地点，主界面顶部的“更换地点”可随时重新选择

## 选择卫星

默认观测清单包含国际空间站和中国空间站，地图同时显示本地目录中的 GNSS 位置

首次联网运行时获取 CelesTrak 轨道目录，点击观测清单中的目标即可查看轨迹和观测信息；打开“卫星目录”，勾选其他卫星即可加入清单

已有轨道文件时，可在卫星目录中使用“导入轨道文件”，支持 TLE 文本和 OMM JSON

## 查看过境

1. 在观测清单中选择目标
2. 查看地图下方的过境预报，比较开始时刻、最高高度角、持续时间和光学条件
3. 点击一行过境，地图与观测信息跳到该次过境的最高点
4. 拖动底部时间轴，查看前后的位置变化
5. 点击“回到现在”继续实时跟踪

“光学条件”表示过境期间卫星受光且观测地点达到暮光条件，实际观测还需结合云量、亮度与周围遮挡，详细判定见[计算说明](calculations.md#过境与光学条件)
