# 使用手册

[返回首页](../README.md) · [开始使用](getting-started.md)

## 观测清单与卫星目录

观测清单保存常用目标，左栏搜索框筛选清单中的卫星，右侧角度表示该卫星在所选时刻的高度角

卫星目录保存已获取或导入的轨道对象，支持名称、NORAD ID、国际编号和已有 PRN 的搜索，勾选卫星即可加入观测清单

GPS、GLONASS、伽利略、北斗与 Starlink 按星座分组，展开分组可查看具体成员；目录数量表示本地已有对象，来源分组数量表示所选数据源的记录数，卫星服务状态应结合官方星座状态资料查阅

星座预览可选择当前达到最低高度角、即将过境或全部位置，其中即将过境范围为未来 15 min，完整 24 h 轨迹随当前选中目标显示

空间站已对接舱段按组合体归组，中国空间站以天和核心舱 `TIANHE / CSS` 为代表，具有独立轨道的航天器保留为单独对象

## 地图

滚轮或加减按钮可缩放地图，拖动可平移，“全球视图”恢复完整世界地图，“跟随卫星”将视图中心保持在目标附近

“展开地图”扩大地图显示区域，“收起地图”恢复过境表和详情栏；左右栏可拖动分隔处改变宽度，较窄窗口通过“目标详情”查看右侧信息

| 图层 | 含义 |
| --- | --- |
| 过去 | 所选时刻之前的推算轨迹，橙色虚线 |
| 未来 | 所选时刻之后的推算轨迹，青色实线 |
| 目标 | 观测清单与当前预览对象的位置 |
| GNSS | 本地目录中的导航卫星位置 |
| 覆盖范围 | 按最低高度角计算的地面范围，采用球面近似 |
| 昼夜线 | 地球日照与夜间区域 |
| 城市、地点、国界、湖泊、经纬网 | 地理参照图层 |

“地图选点”用于设置观测位置，点选后可确认坐标、海拔、最低高度角与时区

## 时间轴与过境预报

实时状态下，时间范围覆盖当前时刻前后各 12 h；拖动后以所选时刻查看目标位置，点击“回到现在”恢复实时状态

时间轴标出过境区间以及入影、出影事件，“现在”刻线与可拖动的时间指针分别表示真实时间和正在查看的时间

过境表中的开始与结束按观测地点的最低高度角计算，最高点给出时间和高度角，点击过境行即可查看峰值时刻

过去位置采用所选轨道根数向过去推算，轨道快照保存的是获取时的根数资料

![过境与地影事件时间轴](images/timeline.png)

## 观测信息

“观测”页顶部显示天空图、高度角、方位角、距离和接近或远离的速度，轨道状态与可见性信息分别列出

| 信息 | 含义 |
| --- | --- |
| 方位角 | 从正北起顺时针计角，正东为 90° |
| 高度角 | 相对当地几何地平面的角度，正值位于地平线上方 |
| 距离 | 观测者与卫星之间的直线距离 |
| 距离变化率 | 正值表示远离，负值表示接近 |
| 卫星高度 | 相对 WGS84 参考椭球的高度 |
| 运行速度 | 卫星在 TEME 坐标系中的速度大小 |
| 星下点 | 卫星在地球表面的经纬度 |
| 卫星受光 | 日照、半影或本影状态 |
| 视星等 | 结合参考星等、距离和相位角得到的大气外亮度估算 |

## 视星等

匹配到内置星等资料的卫星自动参与计算，在地平线上方且完全受光时显示估算结果

打开“星等参数”可填写参考星等、参考相位角、来源与资料日期，参考距离固定为 1000 km，相位角可选满相 0° 或半相 90°

“导入星等表”支持 QuickSat `.mag` 文件，导入时可填写来源标明的发布日期或观测截止日期

手动参数优先于导入资料，导入资料优先于内置资料；“恢复默认”使用对应的内置值，当前采用的来源和日期可在“资料”页查看

云量用于评估观测天气，视星等采用大气外估算，实测亮度还受姿态、镜面反射、大气消光与云层影响

## 无线电

在“无线电”区域填写标称频率，单位 MHz，程序显示多普勒频移与校正后的接收频率

卫星接近时频率升高，远离时频率降低，结果随所选时刻和观测地点变化

## 轨道与资料

“轨道”页保留 NORAD ID、COSPAR 国际编号、历元、倾角、升交点赤经、偏心率、近地点幅角、平近点角、每日绕地圈数、BSTAR 阻力项、历元圈数及平均运动导数项，可复制参数或保存轨道 JSON

“资料”页显示轨道来源、获取时间，以及星等资料的来源、日期和本地记录时间，可切换已保存的轨道快照

CelesTrak 同一来源成功获取后间隔至少 2 h 再次下载；下载失败时，界面显示可重试的时间，通常至少等待 60 s，服务端要求更长等待时按其要求执行

## 天气与设置

天气包括总云量、分层云量、能见度、相对湿度和降水概率，由 Open-Meteo 按地点坐标提供小时预报

设置中的“获取观测天气预报”控制天气查询，“实时更新频率”可在 1–60 Hz 之间选择，默认 1 Hz，表示位置与观测数据的更新频率；画面显示还受屏幕刷新率与绘图耗时影响

顶部月亮图标切换深色和浅色界面

## 本地保存

轨道快照、导入记录与手动星等参数保存在 `%LOCALAPPDATA%\ASTROCHRON\ASTROCHRON\orbits.sqlite`，观测地点、清单和界面设置使用 Windows 用户配置保存

已有本地轨道资料时可离线查看地图、推算轨迹与过境，天气和在线目录查询需要网络连接
